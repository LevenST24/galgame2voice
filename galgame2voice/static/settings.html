🔒 安全控制与日志审计

端到端 API Key 脱敏机制、零泄漏日志过滤与诊断审计

🛡️ 凭据脱敏安全规范说明
  • 前端脱敏传输： 所有 API Key（如 OpenAI、DeepSeek、Telegram Token）在返回前端时均经过 mask_api_key 过滤为 sk-****cdef 或 123****fGhI。
  • 保留旧密钥更新机制： 表单提交时若保持掩码或留空，系统后端将自动保留数据库中现有的原始密钥，避免重复录入与意外覆盖。
  • 日志零泄漏过滤器： 内置 MaskingFilter 会对所有控制台标准输出、文件日志以及 Uvicorn 请求日志中的密钥、Token、Bearer 标头进行正则擦除。
  • URL 安全： 密钥与 Token 严禁在 URL Query 参数中明文传输。
