# Windows 便携版使用说明

适用于 Windows 10/11 64 位。发布包自带 Python、应用依赖和 FFmpeg，无需安装 Python、Node.js 或 Docker。

## 第一次使用

1. 下载文件名以 `windows-x64.zip` 结尾的发布包，右键选择“全部解压”。不要在压缩软件内部直接运行。
2. 将完整目录放到有写入权限的位置，例如“文档”；不要只复制 exe，也不要放到 Program Files。
3. 双击 `启动.bat` 或 `Galgame2Voice.exe`。浏览器会在服务就绪后自动打开。
4. 在全局设置中填写自己使用的对话模型服务地址、API Key 和模型名称。
   使用 Ollama、LM Studio 或局域网模型时，先在“对话模型”中开启“允许私网 LLM 端点”，等待连接范围保存成功，再测试并启用模型。此选项默认关闭；只填写你信任的服务地址。
5. 如需角色语音，先准备包含运行环境的 GPT-SoVITS 完整引擎包与自己有权使用的模型。
   引擎下载入口见 [GPT-SoVITS 官方 Windows 安装说明](https://github.com/RVC-Boss/GPT-SoVITS#windows)，选择包含运行环境的集成包。
   在“全局设置 → 语音服务”中点击“选择文件夹”，选择包含 `api_v2.py` 的引擎目录，再点击“保存目录”。随后在“运行状态”中启动或重启引擎，无需编辑配置文件。
   将完整解压后的引擎文件夹与 `Galgame2Voice` 文件夹并排放置并保存后，两者可随上层文件夹一起移动；程序会重新解析相对位置。
   已经运行的引擎也可在“全局设置 → 语音服务”中配置服务地址。
6. 在会话设置中选择模型权重和参考音频，创建并绑定音色。发布包不预置游戏角色、模型权重或个人 API Key。

程序会自动探测端口、打开浏览器；关闭启动窗口会停止本程序及它拉起的语音引擎。
同一目录重复双击启动会打开已运行的网页，不会再开一个服务；首次启动尚未完成时请等待原窗口。
程序启动不需要下载运行依赖；使用在线对话模型仍需要网络和相应的服务账号。

## 文件夹与更新

- `data`：数据库、设置和凭据。备份时保留整个目录。
- `audio`：生成的语音和缓存。
- `characters`：用户导入的角色包。
- `logs`：遇到问题时查看启动与引擎日志。
- `_internal`：程序自带的运行环境，请勿删除或单独移动。
- `tools/ffmpeg.exe`：自带的音频转换工具。

更新时先关闭程序，将新包解压到新目录，再复制旧目录的 `data`、`audio`、`characters`。
如果自行创建过 `.env`，也应复制该文件；它可能包含服务地址与个人设置。不要用新包的 `.env.example` 覆盖它。
Windows 凭据使用 DPAPI，换 Windows 用户或另一台电脑时，原加密凭据可能无法读取，需要重新填写。
网页会话也会保存在浏览器中。换浏览器或端口前，可在“全局设置 → 备份与更新”导出完整聊天备份，再导入到新网页；导入会新增会话，现有会话不会被覆盖。

## 数据备份与恢复

- 聊天备份 JSON 包含文字消息和会话设置；导入后的历史也会存入本机数据库，可继续用作模型上下文。音频录音、角色文件和服务密钥不包含在 JSON 中，仍需保留 `data`、`audio`、`characters`。
- “导出完整聊天备份”会读取数据库中的完整记录，包括未打开的对话和较早消息。当前网页与数据库不一致的文字会另存为“浏览器副本”，两份都保留；导入保留原消息时间。建议等当前回复完成后导出。
- 服务连接不上时，可先点“仅导出浏览器记录”保留网页里的文字；此文件不包含尚未加载的数据库历史，服务恢复后应再导出完整备份。
- 单份聊天 JSON 上限为 20 MB、10000 个会话、50000 条消息（每个会话至多 10000 条）、1000 万文字字符。超出时不会截断导出；关闭程序后备份整个 `data` 文件夹，并另存浏览器记录。
- 音色编号与安装目录有关，导入会话后请重新选择音色，以免绑定到另一个角色。
- 浏览器存储受限或已满时，网页会明确提示，并保留当前显示的消息。先导出备份，再检查存储权限或删除不需要的会话，点击“恢复本地保存”重试。
- 浏览器中的原记录损坏时，不会用空记录覆盖它；如有上一份有效快照，会先恢复显示。在“备份与更新”导出原始记录后，再选择“恢复本地保存”。
- 已有数据库在启动时每天自动生成一次经过校验的快照，版本升级前另建一份，最近 5 份存放在 `data/backups`。快照包括已提交但尚未合并到主文件的 SQLite 日志数据；它不是持续实时备份。
- 数据库损坏导致网页无法启动时，先关闭程序并保留整个 `data` 目录，双击 **`数据恢复.bat`**，选择备份序号并输入“恢复”。程序会校验备份，另存现有数据库及日志文件，再恢复；恢复前的原文件放在 `data/backups/before_restore_*`，不会随普通快照自动清理。
- 恢复会回到所选备份的时间，之后的修改不在该快照中。没有可用备份时不会创建空数据库替代原文件，请保留数据和启动日志以便进一步排查。
- 数据库快照包含私人记录和凭据数据，分享日志时不要附带数据库、聊天备份或整个 `data` 目录。数据库恢复不改动主密钥或浏览器本地记录。

## 排查启动失败

- 确认已经完整解压，且 `Galgame2Voice.exe` 与 `_internal` 位于同一目录。
- 如果安全软件拦截，先核对发布包的 SHA-256 与来源，再按本机管理要求处理。
- 如果窗口提示语音引擎未找到，网页仍可打开；配置引擎后才能生成角色语音。
- 若 GPT-SoVITS 缺少自己的 `runtime/python.exe`，请换用完整引擎包。便携程序不是语音引擎的 Python。
- 可在目录中打开终端，运行 `Galgame2Voice.exe --check-only` 获取依赖与硬件诊断。
- 便携启动器捕获到启动异常时，会将详细错误写入 `logs/launcher_error.log`，便于排查。
- 提示“数据库来自较新的版本”：错误会列出数据库版本和程序最高支持版本，请使用支持该数据库的新程序。这是版本兼容检查，不能靠恢复同版本备份解决；保留整个 `data` 目录，不要手工降低数据库版本号。

## 使用中遇到问题

- 网页提示连接不上本机服务：保留启动窗口；如果已关闭，重新双击 `启动.bat`，再刷新网页。当前网页中已经收到的回复会保留。
- 回复中途断开或长时间没有数据：程序会结束等待并保留收到的文字，检查网络或模型服务后可重新发送上一条消息。程序不会自动重发聊天，以免产生重复回复或重复计费。
- 语音暂时无法播放：程序会跳过加载失败的片段并保留文字，稍后可点击该条消息重试。网络故障不会清空原有音频记录；确认旧音频已不存在时才会重新合成。加载过程中再点一次可取消等待。
- 浏览器暂停自动播放：点击消息旁的播放按钮继续。手动暂停后，新生成的文字会继续显示，语音和逐句立绘台词会保持暂停；切换会话会停止旧会话的播放。
- 保存配置失败：输入会保留，检查提示后重试。普通配置遇到连接中断时，程序会读取一次已保存值确认结果，不会自动重复保存。密钥等无法安全比对的内容仍会提示确认后再试。
- 删除对话失败：列表和文字会保留，恢复连接后可重试。删除对话不会立即删除共用语音文件，缓存仍按保留时间自动清理。
- 引擎重启显示“正在加载”：这是准备模型的正常阶段。界面确认服务可用后才提示就绪；CPU 首次启动可能较慢，请等待或稍后刷新状态。
- 模型切换提示内存不足：关闭占用内存或显存的程序，或在“语音服务”选择 CPU 模式后重启引擎。程序会保留内存保护，文字聊天可继续使用。
- 引擎目录失效或运行环境缺失：在“语音服务”重新选择完整解压且包含 `runtime` 的引擎目录；无需修改 Python 代码。
- 引擎由其他窗口启动：可直接使用现有引擎；需要更改推理模式时先关闭那个引擎窗口，再从网页启动。
- 立绘不显示：先在“会话设置”选择角色，并确认角色包包含 `portrait` 目录及对应图片。只有模型和参考音频的包不含立绘；语音引擎未启动不影响图片显示。兼容 `portrait/expressions.json` 和旧版 `portrait/manifest.json`，无需手工转换。
- 立绘提示连接或图片加载失败：检查启动窗口是否仍在运行、角色包是否完整，随后关闭并重新打开立绘模式重试。切换到没有立绘的角色会清除上一位角色的图片。

## 从源码构建（面向维护者）

在 Windows 64 位环境中：

```powershell
uv sync --frozen --extra desktop
uv run --frozen --extra desktop python scripts/build_windows_portable.py
uv run --frozen --extra desktop python scripts/verify_windows_portable.py dist/galgame2voice-v2.1.0-windows-x64.zip
uv run --frozen --extra desktop python scripts/smoke_windows_portable.py dist/galgame2voice-v2.1.0-windows-x64.zip
```

前端修改后应先在 `frontend` 目录执行 `npm ci` 和 `npm run deploy`。
产物位于 `dist/galgame2voice-v<版本>-windows-x64.zip`，校验文件与其同目录。
上面的冒烟验证会在中文、空格路径解压真实产物，隐藏系统 Python/FFmpeg，检查网页、文件选择器运行库、音频转换和凭据保存。
便携版使用下载新版发布包的方式更新；网页内的 Git 更新适用于源码安装。
