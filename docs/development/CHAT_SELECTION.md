# 聊天中的角色、音色与模型选择

明确选择失效时，不能在未告知的情况下改用另一全局角色或默认模型。聊天中的人设、
音色与 TTS 解析共用 `services/voice_selection.py` 的数据库身份规则；调用者提供当前
连接，不额外打开数据库或绕过现有事务。目录别名匹配在线程中进行，模型和参考音频
准备仍属于 TTS，不属于聊天的人设选择。

优先级为请求音色 ID、选项音色 ID、明确角色名、会话绑定、未指定时的全局默认。
一个明确 ID 无效但同时提供了能唯一匹配的名字时，允许这个明确的名字备用项；
完整选择器仍参与 TTS 缓存键。有效 ID 优先于名字，名称歧义不能借用全局当前音色。
未绑定、未指定的文本聊天仍可使用默认选择，空目录仍可返回没有音色的上下文。

失效音色返回 `VOICE_PROFILE_NOT_FOUND`，名称歧义返回 `VOICE_PROFILE_AMBIGUOUS`。
前端的错误卡、LOG 和提示动作统一进入“角色与会话”。明确的模型 provider ID 不存在
时返回 `PROVIDER_NOT_FOUND`，进入“对话模型”；现存但未全局启用的 provider 仍可被
请求单独选择，且不改变全局启用状态。完全没有指定 provider 时保留原有全局与环境
配置兼容路径。

流式错误携带稳定错误码和状态码；同步 POST、旧 POST 与 GET 接口返回对应的 HTTP
404/409。失败请求不调用备用模型，不启动记忆提取；现有事务和用户消息收尾流程保留。
选择错误不自动重发。用户重新选择并保存后，可以明确重试原提问，不重复添加提问。
目录确认音色已删除也不自动清空原绑定或写回空选择；用户可主动选择替代音色或
“跟随后端当前音色”。更换音色后保留原提问的可见重试入口；已有新输入草稿时，
新草稿优先，不把界面强行切回旧错误。

测试以临时数据库、合成包和模拟模型适配器验证身份，不使用真实人物立绘或密钥。
`tests/test_chat_selection.py` 覆盖服务、接口、默认兼容与别名；
`tests/test_chat_selection_browser.py` 覆盖桌面上的设置入口及重新选择后的重试。
