# 设置入口与返回首页

主界面设置按钮、F8 和首页齿轮统一进入设置中心。聊天体验、角色与会话、模型、语音
服务、运行状态、记忆与备份均为同一个窗口内的分类页，不再关闭中心另开设置弹窗。
`controllers/settings_center.js` 负责编辑器接入、共享页脚及切页生命周期；角色和体验
编辑器继续拥有自己的校验、保存逻辑。单独挂载的 ADV 舞台仍可使用独立体验编辑器。

窗口顶部始终显示“返回开始页”和关闭按钮；Esc 与 Tab 由中心统一处理，嵌入的体验
编辑器不会抢走分类导航的焦点。聊天界面也有首页按钮。`main.returnHome` 停止当前生成/
播放，取消尚未完成的角色设置读取，关闭模态栈，调用舞台的 `prepareHome`
清理本地弹层及播放状态，再打开首页；不删除会话，不清空输入草稿。聊天体验未保存的
预览按关闭或切页逻辑还原；角色草稿在同一次设置窗口的分类切换中保留，关闭后再次
打开重新读取会话值。离开角色页会撤销异步读取所有权，迟到结果不能重新打开窗口。

音频播放任务在等待浏览器唤醒前即登记所有权；返回首页同样能取消尚未开始下载的准备
任务。取消后原调用立即返回 `interrupted`，旧的唤醒结果不会重新发起下载。单句音频
只有一次带取消信号和 1.5 秒时限的唤醒尝试，被浏览器拒绝时显示 LOG 重播指引。

文字的首次显示仍由台词播放器决定。窗口重排、字幕语言切换和打开设置的
`completeReveal` 不能越过等待音频的状态；新台词激活与思考视图会清除上一页的
显示资格。已经开始显示的台词保留原有立即完成重排的行为，不重播或重复朗读通知。
语音同步模式不会因 1.5 秒预览期限提前出字；声音开始时才显示，语音失败、跳过或回复
结束而未提供音频时放行文字。按阅读速度模式继续使用有限预览期限。点击可先看文字，
关闭语音也可立即阅读；等待期间显示“语音准备中”提示。
单句播放器的开始通知以运行中的 `AudioContext.currentTime` 为准；浏览器计时器
到点后仍需核对音频时钟，暂停或中断期间不放行文字。等待计时器由该句播放任务
持有，停止、关闭或切换会话时一并清理；恢复后只有一次开始通知。
`tests/test_voice_reflow_browser.py` 以真实 DOM 验证桌面尺寸下的等待与恢复。

首页禁用聊天控件时不禁用聊天体验弹层；对应 CSS 也允许它在首页上方显示。离开首页
后快捷菜单显式恢复可见，避免可见性继承导致按钮有布局却无法点击。

`tests/test_settings_navigation.mjs` 检查入口、面板切换和记录/草稿保留。
`tests/test_settings_navigation_browser.py` 用真实页面与合成 API 检查桌面宽度；
点击前检查按钮尺寸、inert 与 `elementFromPoint` 命中，不能仅凭程序调用 click 判定可用。
浏览器测试还使用原生 AudioContext 的暂停状态，模拟延迟唤醒后从设置页返回首页，
检查取消结果在唤醒前送达、旧音频不会下载；乱序唤醒与关闭清理由
`tests/test_stream_audio_recovery.mjs` 的隔离播放测试覆盖。
`tests/test_unified_settings_browser.py` 验证只有一个可见对话框、共用窗口尺寸、跨页草稿、
分类焦点可达、Esc 退出和返回开始页；测试不使用真实配置或角色资源。
