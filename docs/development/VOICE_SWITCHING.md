# 会话切换与语音模型状态

当前会话绑定、数据库保存的启用音色、引擎已经加载的模型是三个不同状态。
立绘和人设跟随会话绑定，语音失败不阻止切换会话或显示立绘。

手动切换的同步资源预检与切换前后内存清理由工作线程执行，切换锁仍覆盖整个
流程。预检阶段取消不会继续调用模型切换。引擎确认切换后，清理和所要求的启用
音色保存由受保护的收尾任务完成；重复取消不提前释放锁，收尾结束后再向调用者
传递取消，不继续预热。数据库写入失败通过 `VOICE_PROFILE_SAVE_FAILED` 明确报告，
不返回切换成功、不继续预热；缺失配置记录造成的零行更新也不算成功。保留已加载
的模型，用户检查目录写权限和剩余空间后可重新选择同一音色，只补做保存，不重复
加载。保存的默认音色不用于填充引擎的已加载状态，首次启用仍需实际加载模型。
这些行为不宣称跨引擎与数据库事务原子性。`tests/test_voice_resource_responsiveness.py` 使用线程门闩与临时
SQLite 验证响应性、取消和启用音色保存，不读取真实模型或数据库。

`voice_settings.js` 的 `ensureSessionVoice` 用同一页面内的 Promise 链串行执行
语音切换，每次调用推进选择版本。任务开始前检查版本、当前会话及原绑定，
已过时或被移除绑定的排队任务直接结束。已经送出的请求等待成功、失败或
现有 120 秒总时限后再继续；不会通过取消旧请求来假定服务端没有修改模型。
旧结果不发布到新会话，也不会让队列拒绝后续选择。

`fetchVoiceProfiles` 仍可更新角色目录，但读取开始时记录启用状态版本。
实际切换请求开始和结束会推进该版本；跨越切换的旧列表不能用旧启用 ID
覆盖已经确认的结果。列表获取失败时，已绑定音色仍可直接按 ID 请求切换；
接口确认 404 且新列表也确认缺失时，仍保留显式绑定并提示重新选择。只有用户主动
选择新音色、选择“跟随后端当前音色”或执行删除操作时才改变绑定；读取状态不代替选择。

首页进入聊天时，即使保存的启用 ID 等于会话绑定，也调用切换接口核验。
服务端在模型、文件版本和参考音频仍匹配时走已加载分支，不重新加载权重。
同一 ID 的正常核验不重复提示成功；失败仍保留语音状态检查入口。这同时
处理首页预览请求尚未完成、启动加载失败和引擎重启后的情况。

保证范围是同一页面发起的切换顺序。其他浏览器、Telegram 等独立调用方由
服务端的切换锁和合成身份检查协调；网络超时不证明引擎已经停止处理旧请求，
后续切换仍需经过服务端验证。文字聊天和立绘不依赖切换请求的完成。

`tests/test_voice_switch_order.mjs` 覆盖 A→B→A、过时排队选择、加载失败后进入
聊天、迟到列表、临时列表故障、请求失败、绑定移除及超时后的继续切换。
`tests/test_adv_main.mjs` 覆盖实际首页、预览、启动和提示行为。

保存失败时，前端清除已确认启用 ID 的缓存并阻止旧列表恢复该状态，保留会话绑定，
即使停留首页也显示中文说明和“重新选择音色”入口；不自动重发写请求。REST 与
Telegram 共用保存确认逻辑。`tests/test_active_voice_persistence.py` 覆盖真实只读
SQLite、零行更新、异常、重复取消、已加载模型重试及 Telegram 的失败反馈。

启动只解析引擎地址并排队预热，不把数据库记录复制到客户端的已加载模型字段。
健康检查通过也不证明模型已经加载。预热的模型加载和标点探测作为同一个低优先级
任务执行；进入工作任务并取得切换锁后重新读取当前音色，锁持续到探测结束，因此
延迟的健康检查或排队任务不会重新加载旧选择。排队期间不占用切换锁。
加载前沿用手动切换的内存预检，不写启用音色配置。模型请求保留原有单次超时，
探测最多 15 秒，排队和整个预热最多 600 秒；取消后调度器取消并回收实际执行任务。
`tests/test_voice_warmup_state.py` 验证启动后首次 HTTP 切换、离线、延迟健康检查、
排队取消、加载失败、资源不足以及真实调度器取消后继续手动切换。

每次预热均生成独立的完整 UUID 任务标识；同一音色重复预热不共享任务 ID。
带缓存的普通及文件合成保留轮次、缓存键前缀用于追踪，随机部分也使用完整 UUID。
同一调度器中仍注册的显式 ID 再次入队会被拒绝，原任务及其取消归属保持不变。
取消释放 ID 后允许复用，旧执行仍可能进行收尾；调度器只清理同一任务对象拥有的
登记，不移除同轮次的替代任务，也不通过旧轮次的残留 ID 取消其他轮次的新任务。
这些约束针对同一事件循环中的调度器；`tests/test_tts_task_identity.py` 覆盖字节和
流式入队、取消后的 ID 复用、跨轮次取消，以及完整服务路径中的短 UUID 前缀碰撞。
